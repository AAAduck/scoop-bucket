# Scoop bucket · VaultGuard

[VaultGuard](https://github.com/AAAduck/VaultGuard) 的 Scoop 清单（网盘伪装加密保险箱：
把私密文件加密成普通图片 / Word 文档，离线单文件）。

## 安装

```powershell
scoop bucket add aaaduck https://github.com/AAAduck/scoop-bucket
scoop install vaultguard
```

## 更新

```powershell
scoop update vaultguard
```

清单带 `checkver` / `autoupdate`，会跟随 GitHub Release 自动升级。
